For v2 and later

Your board, in the browser.

Plug in a board running RPCortex v2 and work with it from a web page: a terminal, its files, commands, packages from the repository, new firmware, and what the device is and runs. Nothing to install on the computer.

Open the tool

The tool is not here yet. Until it is, a v2 board is used from a serial terminal at 115200 baud: pkg install <name> installs a package from the repository, and download turns the board into a USB drive for moving files on and off.

This browser cannot open a serial port. Use Chrome, Edge or Opera on a desktop computer. Firefox and Safari do not support Web Serial.

What it does

Terminal

The board's own shell, as a serial terminal would show it.

Files

Browse the filesystem, and copy files to the board and back, each one checked with SHA-256.

Commands

Run a command line and get its output and whether it succeeded.

Packages

Install anything in the v2 repository by name, even on a board with no network.

Firmware

Put a new firmware image on the board.

Device

The version and build, the board, and who is logged in.

A desktop browser that can open a serial port

Chrome, Edge or Opera. Close PuTTY, screen or anything else holding the port first: only one program can have it.

A board on a release newer than v2.00-beta

The tool talks to the board through link mode, which arrived after v2.00-beta. update check and update install on the board bring it up to date.

Logged in on the board

The tool acts as whoever is logged in, with the same permissions, as if each command were typed at the prompt.

Running v1, the MicroPython line? Its tools are the web installer, the updater and the package page.
