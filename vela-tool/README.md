# vela-tool (placeholder)

This folder is where the RPCortex browser tool is published, at
`rpc.novalabs.app/vela-tool/`. Its source is `tools/web` in the RPCortex
repository, and nothing here is edited by hand: `tools/sync-vela-tool.sh`
replaces the whole folder with a copy of it and writes `SOURCE.json`, which
names the commit the copy came from.

Until the first copy lands, the `SOURCE.json` here names no commit and `tool.html`
says the tool is not here yet.
