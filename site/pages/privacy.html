Privacy policy

Summary

RPCortex is software that runs on your own microcontroller. On its own it is offline: it collects no personal data and sends nothing to us. It contacts the internet only when you run something that needs to (an update check, the package manager, time sync, or an app you install), and then your device talks directly to the service involved. The data does not pass through us.

This website uses no cookies, no analytics, no advertising and no tracking scripts, and loads no fonts or scripts from third parties.

Scope

This policy covers this website (rpc.novalabs.app) and the RPCortex operating system you install on a Raspberry Pi Pico, Pico W, Pico 2 or Pico 2 W. It is published by dash1101, based in the United States. This website

  • Hosting. The site is static files served by GitHub Pages. Like any host, GitHub may record routine request data such as your IP address and browser in its own logs; that is governed by GitHub’s privacy statement.
  • Nothing stored in your browser. The site sets no cookies and uses no local storage. Fonts and scripts are served from this site.
  • Release information. The release bar, the Releases page, the Get page and the home page read the release list and the firmware images from GitHub (raw.githubusercontent.com) in your browser. Nothing about you is sent beyond a normal web request.
  • Browser installer, web installer and package browser. They use your browser’s WebUSB or Web Serial to talk to a board you plug in yourself. That conversation is between your browser and your board; firmware and package files are sent to the device locally and are not sent to us. The package browser fetches the package index and files from GitHub.
  • Links out. Pages link to GitHub, Discord and similar services, which have their own policies.

The RPCortex OS

The operating system runs entirely on your device and is offline until you use a network feature. It contains no telemetry and does not report back to anyone.

Data on your device

RPCortex keeps the following on the device’s own flash, and none of it is sent to us:

  • Accounts. Usernames and salted SHA-256 password hashes (/os/users.cfg). Passwords are not stored in a reversible form.
  • Saved Wi-Fi networks. The password is sealed under a key unique to the device (/os/device.key) before it is written to the settings file, so a copy of that file, a backup or a support dump does not hand it over. The key is left out of backups. This protects a copy of the file, not the board: there is no secure element, so someone holding the whole flash can recover the password. Treat the board like a key.
  • Settings. Device name, owner, time zone and preferences, in the registry.
  • Logs and crash reports. A log ring in memory, and the last crash report in /os/crash.log. They stay on the device.
  • A saved copy of the previous firmware, so an update can be undone.

Network features

These reach the internet only when you use them. In each case the device connects to the service directly.

  • Over-the-air updates (update check, update install) download a version manifest and a firmware image from GitHub (raw.githubusercontent.com). The request carries what any web request does, including a user agent of RPCortex/2.0. Images are checked against a SHA-256 before anything is written.
  • The package manager (pkg) downloads the package index and packages from GitHub, each checked against its SHA-256.
  • Time sync (ntp sync) contacts an NTP server, pool.ntp.org by default.
  • Web search (the optional websearch package) sends your query to DuckDuckGo and Wikipedia.
  • General networking (wget, curl, ping, nslookup, runurl) contacts whatever hosts you point them at. runurl fetches code to run and asks first.
  • The built-in web server (the optional httpd package) serves files from your device to other clients on your network. Run it only on networks you trust.
  • Bluetooth and other radios are used only when you run a command that uses them.

What we do not collect

  • No analytics, telemetry or usage tracking.
  • No accounts on our servers: accounts exist only on your device.
  • No advertising and no ad or tracking networks.
  • We do not sell, rent or share personal data, because we do not collect it.

Security

  • Account passwords are salted and hashed on the device and are never stored or sent in plaintext.
  • Saved Wi-Fi passwords are sealed under a per-device key; see the limit stated above.
  • Firmware and package downloads are verified against a checksum before they are used.
  • No system is perfectly secure. For a device on an untrusted network, leave httpd off and do not store secrets you cannot afford to expose.

Third parties

Depending on what you use, your device or browser may contact GitHub and GitHub Pages (hosting, firmware images, packages), public NTP servers, and DuckDuckGo and Wikipedia (the websearch package). We are not responsible for their practices; read their policies.

RPCortex v1

The older MicroPython release behaves the same way with two differences worth knowing: it stores saved Wi-Fi passwords in plaintext on the device (/Vela/Registry/networks.cfg), and its update host is this site rather than GitHub.

Children

RPCortex is a maker and developer tool and is not directed at children under 13. We do not knowingly collect information from children.
