Versions

How versions work

  • Every release takes the next number. v2.00-beta was the first, v2.01-beta the next. A number is never reused, and a later number is always newer. There is no patch number, and the count does not stop at nine: v2.09 is followed by v2.10.
  • A label says how finished it is. -beta, then -rc and -rc2 for release candidates, and no label once it is final, as in v2.06.
  • Only a generation has a name. Vela, Vela II, and whatever comes after. A change that breaks packages is a new generation, which is what lets any release in a generation be installed without reading the notes first.
  • The build number is separate. ver shows v2.01-beta (build 520); the device uses it to decide what is newer. Builds between two releases are not published.
