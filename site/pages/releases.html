Versions

How versions work

  • A version is three numbers. v2.0.640-beta is generation 2, line 0, build 640. The build is the count of changes made so far, so every release has a number of its own and a later number is always newer.
  • The middle number is a step in what it runs on. v2.0 is the Raspberry Pi Pico family; v2.1 will be the ESP32 port. It does not move for every release.
  • A label says how finished it is. -beta, then -rc and -rc2 for release candidates, and no label once it is final.
  • Only a generation has a name. Vela, Vela II, and whatever comes after. A change that breaks packages is a new generation, which is what lets any release in a generation be installed without reading the notes first.
  • The first releases counted differently. v2.00-beta to v2.05-beta used a plain release count. A device on one of those moves to the new numbers once, with sudo update online --force; after that, updates are offered as usual.
