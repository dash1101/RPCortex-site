Versions

How versions work

  • v2.11 means the eleventh iteration of the second generation. There is no patch number, and the count does not stop at nine: v2.9 is followed by v2.10.
  • Only a generation has a name. Vela, Vela II, and whatever comes after. An iteration is a plain patch release.
  • A change that breaks packages is a new generation. That is what lets an iteration be installed without reading the notes first.
  • The build number is separate. ver shows v2.11 (build 1203); the device uses it to decide what is newer. A pre-release is written v2.0-beta.
