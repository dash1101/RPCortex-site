What this does. It downloads the same .uf2 as the Get page, checks it against the published SHA-256, and writes it to the board through the boot ROM, the way picotool does: erase, write, read back, restart. Your files and settings are not touched; only the firmware area is written. When it finishes the board restarts; open a serial terminal at 115200 baud.

  
If the board cannot be opened. Another program may be using it (close picotool, other tabs or serial tools). On Windows the browser can only open the board when a WinUSB driver is bound to its boot interface; if it cannot, the drag-and-drop install is the way. On Linux the board needs a udev rule that lets your user open it.
